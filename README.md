# Basketball Project

## Quick Start (اجرای سریع پروژه - Cross-Platform)

یک فایل واحد بر پایه Bun بنام [run.ts](file:///home/reza/Desktop/basketball/run.ts) آماده شده است که هم روی **ویندوز** و هم روی **لینوکس** هر دو سرویس فرانت‌اند و بک‌اند را هم‌زمان اجرا می‌کند:

### در هر دو سیستم‌عامل (Windows & Linux):
```bash
bun dev
# یا
bun run.ts
```

### در لینوکس (Linux):
```bash
./run.ts
# یا
./run.sh
```

### در ویندوز (Windows):
می‌توانید روی فایل `run.bat` دابل‌کلیک کنید یا در CMD / PowerShell بنویسید:
```cmd
run.bat
```
